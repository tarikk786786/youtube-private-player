# YouTube Private & Members-Only Video Player / Downloader

> Modern desktop GUI utility powered by CustomTkinter and `yt-dlp` for streaming and downloading unlisted, private, and authorized members-only videos using authenticated browser sessions. Crafted by [tarikislam.in](https://tarikislam.in).

---

## 🎯 Features
- **Stream & Play**: Play unlisted and authorized private videos directly in mpv / VLC without ads or restrictions.
- **Browser Cookie Authentication**: Seamlessly extract cookies from Chrome, Edge, Firefox, Brave, or Opera without sharing passwords.
- **High-Definition Downloads**: Support for 4K, 1080p, 720p, and audio-only extractions (MP3/M4A).
- **Clean Modern UI**: Dark/Light mode interface built with CustomTkinter.

---

## 🚀 Quickstart

### Prerequisites
- Python 3.10+
- FFmpeg installed and on system PATH

### Installation
```bash
pip install -r requirements.txt
```

### Run
```bash
python youtube_private_player.py
```
Or double-click `run.bat`.
